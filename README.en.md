Four front-end exercises in plain HTML, CSS and JavaScript to practice reading inputs, changing the DOM, dynamic styles and form validation.

## Exercises

They live in `Manipulação do DOM e Validação em JavaScript/`, sharing one `style.css`.

| Question | What it does | Concepts |
| --- | --- | --- |
| `questao_01` | Reads the typed text and sets it as the title; with an empty field, shows a warning in red | `getElementById`, `value`, `innerText`, `style` |
| `questao_02` | Toggles an element between square and circle and changes the button label | `getComputedStyle`, `borderRadius` |
| `questao_03` | Sign-up with name, birth date and address that builds a sentence from the entered data | reading several fields, template literals |
| `questao_04` | Validates required name and CPF fields and the CPF format (`000.000.000-00`) with a regular expression, showing an error or success message | regex, conditionals, visual feedback |

Events are wired through the buttons' `onclick` attribute. The UI text is in Portuguese.

## Running

No dependencies. Clone the repository and open each question's `.html` file in a browser:

```bash
git clone https://github.com/Luisr-nunes/Manipula-o-do-DOM-e-Valida-o-em-JavaScript.git
```
