## 📋 Sobre este Repositório

Neste projeto, o foco é a programação web base sem a utilização de bibliotecas ou frameworks externos. O código demonstra como o JavaScript atua diretamente no *Document Object Model* (DOM), capturando eventos de tela e realizando a validação de formulários complexos no lado do cliente, fornecendo feedbacks visuais imediatos ao usuário.

---

## 📁 Estrutura da Aplicação

| Arquivo | Tipo | Descrição |
|---|---|---|
| `index.html` | 📄 HTML | Estrutura semântica do formulário e elementos de tela |
| `style.css` | 🎨 CSS | Estilização da interface, incluindo estados de erro/sucesso |
| `app.js` | ⚙️ JS | Event Listeners, manipulação do DOM e lógica de Regex/Validação |

---

## 🎯 Funcionalidades Implementadas

* **Leitura e Escrita Dinâmica:** Captura de inputs do usuário e exibição de dados processados na tela.
* **Validação em Tempo Real:** Verificação de campos obrigatórios, formatação de e-mail e regras de senha antes do submit.
* **Prevenção de Comportamento:** Uso de `preventDefault()` para manipulação total do envio do formulário.

---

## 📌 Como Testar

1. Baixe os arquivos do repositório ou realize o clone via Git.
2. Abra o arquivo `index.html` diretamente em qualquer navegador web moderno.
3. Tente submeter o formulário vazio ou com dados incorretos para testar as regras de validação aplicadas.
